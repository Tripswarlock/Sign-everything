**PDF/File Signer (КриптоПро)**

Простое GUI-приложение на Python (PyQt5) для массового подписания файлов с помощью утилиты cryptcp из КриптоПро CSP. Поддерживает перетаскивание папок, выбор сертификата, отображение прогресса и остановку процесса.

**Возможности:**
Перетаскивание папки в окно (drag & drop) или выбор через диалог

**Автоматическое сканирование:** подсчёт всех файлов, уже подписанных и подлежащих подписанию

Рекурсивная обработка всех вложенных папок

Подписание файлов любых форматов (отсоединённая подпись .sig)

Автоматическое исключение уже подписанных файлов (.sig)
